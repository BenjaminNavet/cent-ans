# Politique de sécurité

## Versions prises en charge

Cent Ans est en développement actif : seule la branche `main` reçoit des correctifs.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique** pour une faille de sécurité (par exemple un fichier de sauvegarde
ou de mod piégé qui exécute du code, ou un problème dans le processus de build).

Utilisez le [signalement privé de GitHub](https://github.com/BenjaminNavet/cent-ans/security/advisories/new)
(onglet *Security* → *Report a vulnerability*). Indiquez :

- la description du problème et son impact ;
- les étapes pour le reproduire (fichier d'exemple si possible) ;
- la version ou le commit concerné, et votre plateforme.

Vous recevrez une réponse sous quelques jours. Le correctif sera publié puis la faille annoncée,
avec votre nom si vous le souhaitez.

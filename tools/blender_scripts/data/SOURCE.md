# Courbes d'allures du cheval (lot AS8b)

`horse_gaits_free.json` : trajectoires de sabots mesurées par `tools/video_mocap/track_quadruped.py`
(points posés à la main dans `tools/video_mocap/data/horse_keypoints.json`, lissés en séries de
Fourier), puis écrétées par `battle_skinned_gaits.py`. Seules ces courbes sont versionnées ; les
images restent hors dépôt (`~/dev/cent-ans-mocap-src/video/free/horses/`, un `.LICENSE.txt` par
fichier, licence lue par l'API Commons le 08/10/2026).

attribution n'est requise, elle est donnée par courtoisie.

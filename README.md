# Cent Ans

Jeu de grande stratégie solo inspiré de Total War, situé pendant la guerre de Cent Ans (1337-1453).
Carte de campagne au tour par saison, batailles en temps réel avec pause, gestion des villes,
dynasties, diplomatie, religion et technologie.

- Conception : `docs/design/2026-09-23-cent-ans-design.md`
- État du projet : `docs/status.md`
- Feuille de route : `docs/roadmap.md`
- Budget cloud : `docs/budget.md`

Stack : Godot 4.7 (GDScript) + Rust (GDExtension) + Blender 5.2 + Python (uv).

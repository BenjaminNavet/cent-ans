# NB0 — Sonde des modèles d'image (30/09)

Planche : `nb0_models.jpg` (lignes : portrait d'Édouard III, Crécy, icône cavalerie ;
colonnes : actuel gpt-5-image-mini, puis NB2 / NB2 Lite / Nano Banana Pro, sans et avec ancre v0).
18 images 1K, 1,44 $ (NB2 0,07 $, Lite 0,03-0,04 $, Pro 0,14 $ l'image, coût réel).
Prompts : construits par `portraits.build_prompt`, `event_art.build_prompt`,
`entity_icons.build_prompt`, préfixés d'une note d'ancre pour les colonnes « avec ancre ».

## Constats (session principale)
- Les trois modèles Nano Banana dépassent nettement l'actuel : vrai trait d'encre, dorure,
  fonds diaprés, héraldique juste (léopards d'Angleterre), compositions de miniature.
- L'ancre rapproche les images du registre choisi (fonds or et azur à rinceaux, bordure fine) ;
  gain le plus visible sur NB2.
- NB2 Lite : très bon pour les icônes, moins sûr sur les visages (portrait avec ancre efféminé).
- Pro : pas mieux que NB2 pour le double du prix ; Crécy avec ancre montre une pseudo-lettrine
  (texte interdit par la bible).
- Toutes ajoutent un cadre ou une marge de vélin : à retirer dans les prompts de reprise
  (portraits plein cadre) ou à rogner.

## Recommandation
NB2 + ancre par défaut ; Lite + ancre pour les icônes en grand nombre.

## Verdict du joueur
NB2 + ancre validé par le joueur (30/09) pour NB1 et les chantiers suivants.

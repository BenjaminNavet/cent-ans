# LR-10 — lacs historiques + retenues modernes du masque terre

Branche `feat/lr-10`, worktree `../gp-lr-10`. Contexte : `hc2-eaux.md`, `ss.md`, ADR 0142 / 0161.

## Conception
- `data/map/historical_lakes.json` (+ schéma) : lacs de 1340 absents ou incomplets aujourd'hui.
  Chaque entrée : enveloppe lon/lat grossière (tracée à la main, quelques km), `level_m` (niveau
  affiché de la nappe), `max_height_m` (seuil de relief pour creuser le masque), sources.
  Le contour réel vient du relief : enveloppe ∩ (hauteur ≤ `max_height_m`). Pas d'OSM.
- `cent-ans geo land-mask` (nouveau, `geo/historical_water.py`) : refait `land_mask.png` depuis
  Natural Earth comme `geo build` (reproduit à l'octet près), sans les polygones NE qui portent
  une retenue de `modern_reservoirs.json`, avec les lacs historiques creusés ; recolle les
  pixels redevenus terre à la province la plus proche (`province_ids.png`).
- `geo build` applique les mêmes filtres (reconstruction complète cohérente).
- `geo lakes` : chaque lac historique donne une nappe (enveloppe ∩ eau du masque), niveau imposé,
  sans critère de planéité ; les bassins automatiques qui la recouvrent sont retirés.
- Dérivés régénérés : `lakes.json`, `navgrid.png` (règle : lacs infranchissables, retenues
  traversables) ; `splat` si reproductible. Colormap, biomes, landcover : non régénérés.

# FPS carte et bataille, gains rapides (10/10)

**État : 3 correctifs commités. Machine chargée (~130) par d'autres sessions : chiffres indicatifs.**
M4 Pro, fenêtre 2624×1644, échelle 3D 0,52, qualité Haute.

## Carte (`--bench-map --bench-pan-only --bench-hover --bench-probe`)
| | avant | après |
|---|---|---|
| d30 : i/s, p50, p99 | 37,8 · 25,3 ms · 65 ms | 43,7 · 22,4 ms · 46 ms |
| d30 : images > 50 ms (20 s) | 13 | 4 |
| `map.settlements` par image | 5,3 ms | 1,1 ms |
| Survol d'une nouvelle province | ~80 ms | ~3 ms |

1. **Maquettes de villes** (`town_maquette_layer.gd`) : fondus par type, vue DN et ombres ne sont
   recalculés que si la distance de caméra change (3,5 ms → 0,01 ms par image).
2. **Roseaux et mares** (`freshwater_layer.gd` `seed_block`) : seuls les cercles d'exclusion qui
   touchent le bloc sont testés (même schéma que `ground_clutter._seed_cell`). Pic 38 → 8 ms ; sortie identique.
3. **Postures diplomatiques** (`get_faction_stances_for`, `get_province_stances`) : un seul
   `PlanCache` par appel au lieu d'un par faction (`diplomatic_stance_cached`). L'appel coûtait ~78 ms
   à chaque changement de province survolée (info-bulle de possession) ; il en coûte ~1,6.

## Bataille (`game/tests/battle_fps_bench.gd`, nouveau banc)
`tools/godot_bg.sh --path game --script res://tests/battle_fps_bench.gd -- --bench-probe --window=2624x1644 --units=30`
France contre Angleterre, IA des deux côtés, 60 régiments : **88-93 i/s, p50 10,6-11,2 ms, p99 14-15 ms**,
~800 appels de dessin, 2,2 M de primitives. Scripts 4,6 ms par image : soldats 1,9, étendards ~1,
effets 0,5 ; la simulation tourne dans un fil. Rien de coûteux : pas de correctif.

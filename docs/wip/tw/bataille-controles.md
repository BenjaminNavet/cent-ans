# TW — critique « bataille-controles » (contrôles en bataille 3D vs M2 / WH3)

## 1. Résumé
Les lots CB (spec `docs/superpowers/specs/2026-09-27-controles-bataille-tw-design.md`) ont déjà livré la grammaire TW : boîte de sélection, double clic = même type (`battle_input.gd:173`, aussi sur carte), Ctrl+A, groupes Ctrl+1..9 (double appui = centrer, `battle_input.gd:138`), verrou de groupe, glisser-droit = ligne avec largeur/orientation (`:196-228`, ADR CB1), Maj+clic droit = file d'ordres, course sur double clic droit, modes garde/escarmouche/mêlée/course (`battle_hotkeys.gd:30-34`), tir à volonté (F), retrait, 6 formations de groupe (Alt+Maj+1..6), capacités Alt+1..4, vue tactique Tab, suivi C, caméra WASD/QE/bord d'écran/bouton du milieu, ralenti ×0,5..×4 et pause avec ordres, cartes (effectifs, moral, munitions, modes, état, cadenas, n° de groupe, `unit_card.gd:247-312`), panneau de comparaison au survol (`battle_compare_panel.gd`, déjà CB-M4), alertes cliquables (CB5), barre de rapport de forces, sceau du chef, aide F1.
Ce qui manque le plus : la **minicarte passive** (clic caméra seulement), l'absence de **pause automatique / alerte « va-y »**, aucun **raccourci reconfigurable** en bataille, pas d'ordre de **pivot sur place**, pas de **signets de caméra** ni de cycle d'unités, pas de menu contextuel sur carte.

## 3. Top 10 (impact/coût)
1. **#1 Ordres depuis la minicarte.** `battle_minimap.gd` : dans `_gui_input`, bouton droit relâché → `signal order_requested(world: Vector2, queued: bool)`. `BattleScene` relie à `BattleInput` : nouvelle méthode `order_move_to(point: Vector3, queued)` factorisée à partir de `_finish_right` (`battle_input.gd:236-239`, passe par `_path_allowed` et groupes verrouillés). Désactiver en rejeu/déploiement (déploiement : placer). Tooltip `battle_minimap_click_camera` mis à jour. Test GDScript : sélectionner un régiment, simuler clic droit minicarte, vérifier la commande `move`.
2. **#2 Pivot sur place.** Dans `_finish_right`, si `press.distance_to(position) > 20` et que `mid` est à moins de ~4 m du centre de l'unité (ou du groupe) alors accepter, sinon le chemin actuel. Le cœur gère déjà `facing`/`width` (`command.rs:Move`). Test cargo : `Move` avec `facing` et destination = position courante tourne l'unité sans déplacement ni erreur.
3. **#5 Signets de caméra.** `battle_camera.gd` : `bookmarks: Array[Dictionary]` (4 entrées `{target, yaw, distance}`), méthodes `save_bookmark(i)` / `recall_bookmark(i)` (`glide_to`). `battle_input.gd` : Ctrl+F2..F4 enregistre, F2..F4 rappelle (F1 = aide inchangé). Lignes dans `BattleHotkeys` (groupe « view », `dispatch:false`, aide F1). Test : sauvegarde puis rappel, la cible converge.
4. **#3 Pause automatique sur alerte.** Réglage `battle/auto_pause_on_alert` (défaut off) dans `settings_menu.gd:_build_battle`. `BattleScene._on_alert` : si actif et alerte `rout`/`general_down`, `paused = true` + toast « Pause : <alerte> (Espace) ». Pas en rejeu. Test headless : alerte injectée → `paused`.
5. **#6 Unité suivante au repos.** `BattleHotkeys` : `{"action":"next_idle","key":KEY_PERIOD}` ; `BattleInput.handle_action` : trouver la prochaine unité du joueur `present`, état `idle`, non retirée, après la sélection actuelle ; sélectionner et `camera_focus_requested.emit`. Test : liste d'unités factice, rotation circulaire.
6. **#9 Attaque au pas.** `_finish_right` : `run = not alt_pressed` (clic droit alt) ; infobulle du curseur `BattleCursor`. Aucun changement cœur. Test : commande `attack` avec `run:false`.
7. **#8 Sélection par classe.** `BattleHotkeys` Ctrl+Maj+A (tireurs), Ctrl+Maj+C (cavalerie) ; fonction `select_class(predicate)` à côté de `select_same_type_of` (`battle_input.gd:557`) lisant `can_shoot` / `class` de `get_units`. Mods `ctrl`+`shift` à ajouter à `mods_of` (aujourd'hui « other »). Test sur `mods_of` + sélection.
8. **#4 Raccourcis reconfigurables.** Étendre `KeyBindings` aux actions de `BINDINGS` (clé par défaut = `key`), `action_for` lit la surcharge ; page « Bataille » dans les réglages ; détecter les conflits. Aide F1 générée déjà par `help_bbcode`. Test : rebind T→Y change `action_for`.
9. **#11 Fiche ennemie sans sélection.** `BattleComparePanel` : variante « fiche seule » si `selected.is_empty()` avec les lignes de type/effectif approximatif/moral qualitatif (jamais les chiffres exacts), sans « avantage net ». Source `hover_context`. Test : le panneau s'ouvre et ne contient que les lignes autorisées.
10. **#7 Clic droit sur carte ennemie.** Les cartes ennemies n'existent pas ; alternative : clic droit sur une carte amie = centrer + sélectionner seule (cohérent WH3). Faible priorité.

## 4. Refontes lourdes (L)
- **Tracé d'ordres complet façon WH3** : chemin multi-points avec tracé persistant, formation au clic final et prévision de temps de trajet par groupe (aujourd'hui la file CB-M3 est bornée et sans temps). Coût L (cœur + aperçu), impact moyen.
- **Caméra libre vs RTS à deux modes** (M2 : caméra libre à hauteur du sol, suivi à la troisième personne avec vue d'unité). Aujourd'hui une seule orbite avec suivi (`battle_camera.gd`). L à cause des collisions relief et du rendu à hauteur d'homme ; surtout cinématique, impact bas pour le jeu.
- **Minicarte tactique complète** (icônes de classe, lignes de front, vue du brouillard, déploiement par minicarte) : L si on veut remplacer les points ; faire d'abord #1 et #13.

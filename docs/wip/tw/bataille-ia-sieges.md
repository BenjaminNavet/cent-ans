# TW — bataille : IA tactique, déploiement, renforts, sièges (critique)

Rôle `bataille-ia-sieges`. Références M2 / WH3. Lecture seule ; état du code au 10-10. Déjà fait (non reproposé) : contrôles TW (CB), formations/rangs RJ, sortie de garnison (`formation_ai.rs:159`, WH armyb top5), sommation (WH), points de capture place+porte (TW2 T4, ADR 0108), feu (`sim/fire.rs`), huile bouillante (`sim/siege_assault.rs:407`), tours de muraille qui tirent (`sim/siege_extra.rs:27`), pont/gué (EP3, RC ADR 0141), embuscade/colonne (CV3-2, `opening.rs`), dernier carré (`capture.rs` LastStand).

## 1. Résumé
- L'IA de terrain est déjà plus fine que celle de M2 : rôles ligne/tireurs/cavalerie/réserve (`ai/roles.rs`), posture défensive (crête, haie, rivière : `ai/plan_field/mod.rs:60-95`), duel d'archers à durée bornée, cavalerie qui charge flancs/tireurs isolés et poursuit avec laisse (`ai/horse.rs:173`), réserve qui bouche (`plan_field/reserve.rs`), régiment flanqué qui se retourne (`plan_field/orders.rs`). Sièges complets : béliers, tours, échelles, brèche, repli sur la place, sortie.
- Ce qui manque le plus : (1) le **devenir des vaincus** après une bataille 3D (aucune poursuite ni prisonniers de troupe : seul le général peut être capturé) alors que l'auto-résolution a une poursuite (`sim-campaign/src/battle_auto.rs:1030`) ; (2) des **renforts en cours de bataille** réels (armée alliée ou de secours qui arrive sur un bord à T+x ; aujourd'hui seul le « surplus au-delà de 40/80 régiments » entre) ; (3) une **IA qui bat en retraite** en rase campagne et une **limite de temps visible** ; (4) en siège, peu de **défense active** (pas de contre-batterie, pas de sape, tours de muraille codées en dur).

## 3. Top 10 (impact / coût)
1. **Poursuite et prisonniers en bataille 3D (#1)**. Fichiers : `core/crates/sim-battle/src/outcome.rs` (`SideResult.captured`, `pursuit_losses`), `sim/morale.rs::check_end` (appel `apply_pursuit(winner)` après `apply_decision`), `data/rules/battle_outcome.json` (`pursuit_base`, `pursuit_per_cavalry`, `captive_share`), `sim-campaign/src/battle_outcome.rs` (applique pertes, convertit captifs en `ransom::add_captive`). Seul le gagnant poursuit ; `no_quarter` tue les captifs ; cavalerie gagnante vivante module. Tests : déterminisme (même graine), pertes ≤ effectif en déroute, rien si `Refused`/`Lull`, parité avec `battle_auto` (même ordre de grandeur).
2. **Retraite de l'IA en rase campagne (#4)**. `ai/plan_field/mod.rs` en tête de `plan_field` : calcul `view.sim.fighting_share(side)`, seuils `retreat_share`, `retreat_ratio`, `retreat_min_time` dans `data/rules/battle_ai.json` + `ai_rules.rs` ; émet `Command::Withdraw` pour toutes les unités non en déroute, avec le général en dernier. Test dans `sim-battle/tests` : armée à 0,3 de force se retire, `BattleEnd` ≠ `Broken`, `withdrew = true`.
3. **Temps restant lisible (#5)**. `godot-bridge/src/battle_sim.rs` : champ `time_left_s` (`MAX_DURATION - elapsed`) dans l'état exposé ; `game/scripts/battle/` HUD : sablier + toast à 300 s, 60 s, avec texte « Défenseur gagnant à la nuit » en siège. Test GDScript headless sur le texte du toast.
4. **Tours de muraille pilotées par les données (#6)**. Retirer les `const` de `siege_extra.rs:15-23` ; ajouter bloc `tower` (+ `sortie`) à `data/rules/siege_works.json` et son schéma ; `SiegeWorkRules::bundled()` les expose ; portée/cadence modulées par `fortification`. Tests : valeurs identiques à l'actuel au niveau 3 (régression), données invalides rejetées par le schéma.
5. **Renforts d'armée à arrivée différée (#2)**. `data-model` : `UnitSetup.arrival_s`/`entry_edge` ; `sim-campaign/battle_request.rs::side_setup` les remplit pour les armées de coalition à distance ; `sim/reinforcements.rs::release_reserves` et `march_in` lisent `elapsed >= arrival_s` et le bord ; IA : l'arrivée renforce la ligne comme les réserves actuelles. Tests : unité arrive à t ± 1 tick, pas avant ; save/replay identiques.
6. **Contre-batterie (#7)**. `ai/siege.rs::plan_siege_defence` : pour chaque tireur de rempart libre, choisir bélier/engin dans `range` (ordre `Command::Attack`) ; retirer l'exclusion dans `siege_extra.rs` pour une option `tower.hit_engines` (bolts faibles). Test : à garnison égale, le bélier est détruit plus tôt qu'avant (comparaison sur graine fixe).
7. **Deuxième point d'assaut IA (#8)**. `ai/siege.rs` : `target_piece` renvoie deux pans distincts quand ≥ 2 engins et ≥ 4 régiments de fantassins ; les échelles de la seconde vague visent le second pan. Test : durée d'assaut médiane ne dégrade pas ; les deux pans reçoivent des coups.
8. **Réaction IA au déploiement du joueur (#9)**. `sim/deployment.rs::start_battle` : si `ai_enabled`, appeler `ai_adjust(side)` : permute ailes de cavalerie vers le flanc le plus faible du joueur, place les tireurs face à la ligne d'infanterie la plus longue (bornes de zone, jamais dans l'eau). Test : déterminisme, unités toujours dans la zone.
9. **Secours de siège (#3)** après #5 : une armée amie voisine entre à l'arrière de l'attaquant ; `plan_siege_attack` détache une garde (réserve) pour la contrer.
10. **Butin de bataille (#11)** : vérifier `standards_taken`/`baggage_lost` → prestige/or dans `sim-campaign/battle_outcome.rs` ; si absent, ajouter via `data/rules/battle_outcome.json`.

## 4. Refontes lourdes (L)
- **Embuscade jouable et camouflage (#10)** : unités cachées (forêt, haies) invisibles tant que l'ennemi n'est pas à < R m ou qu'elles n'ont pas tiré/chargé (règle de visibilité dans `core/sim-battle`, utilisée par IA et rendu `game/scripts/battle/`), déploiement du joueur sur toutes les zones d'`AmbushLayout.zones` (pas seulement `zones[0]`), phase « coup d'envoi » avec bonus de surprise (déjà partiellement : moral du piégé). Prérequis du brouillard de règles ; coût L, impact 4 pour le style médiéval (Azincourt, Crécy-en-Ponthieu).
- **Sape et mines** (M2 : sapeurs, tunnels ; WH3 : sans) : engin `sapper`, tunnel qui abat un pan en N s, contre-mine de garnison. Nouveaux types dans `siege.rs`/`siege_assault.rs`, rendu mineur ; coût L, impact 2 (le bélier/tour/bombarde couvrent déjà le gameplay).
- **Siège à plusieurs enceintes** (citadelle intérieure, M2/WH3 : murs intérieurs) : `SiegeWorks::generate` à deux anneaux et deuxième point de capture ; impact 3, coût L (plan de ville fixe, ADR 0108).
- **Moteurs de siège de garnison** (bombardes/trébuchets sur tours, tirs de contre-batterie à longue portée) : demande des postes d'engins sur `Tower` (`siege.rs`) et unités posées ; couplé à #7.

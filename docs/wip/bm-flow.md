# bm-flow — flux campagne ↔ bataille (client Bevy)

État (wip) : `game-api::flow` (vues), `client/src/flow/` (dialogue d'avant-bataille, rencontres, carte de chargement, avis de résultat, retour de bataille), édition minimale de `battle/scene/mod.rs` (lit `flow::CampaignBattle`).
Prochaine étape : passe `--script` de bout en bout, rapport.
Points ouverts : pas d'autosave avant bataille ; bannière illustrée / minicarte du site / météo prévue absentes du dialogue ; écran de fin 3D = lot battle/hud (flow n'affiche que le bilan en modale sur la campagne).

# bm-menu5
Fait : onglet « Toutes les factions » = carte cliquable (`menu/faction_map.rs`, port de `faction_map_picker.gd`) : provinces de `provinces.geojson` remplies par balayage dans une image 900 px (pas de raster d'identifiants de 43 M pixels), colorées par propriétaire 1337, survol = fiche (souverain, titres, suzerain, royaume, difficulté, objectifs), clic = choix, filtres royaume / rang (boutons à bascule, pas de liste déroulante dans le kit), liste groupée par royaume (sans terre d'abord) avec surbrillance, bannières cliquables des factions sans terre (croisés). Cartes et fiche de droite : portrait du souverain (`portraits/<id>.png`) et chiffres clés (provinces, trésor, revenu, armées). Données : `game_api::start_sheets::feudal_start_sheets` (port de `get_feudal_start_sheets`, ajout hors dossier menu : `core/crates/game-api/src/start_sheets.rs` + une ligne dans `lib.rs`).
Pause : « Aide (F1) » ouvre la feuille d'aide de la campagne en fenêtre modale (Échap ferme la feuille, pas la pause) ; infobulle `pause_difficulty_fixed` sur la ligne de difficulté.
Invite du didacticiel de bataille (`menu/battle_prologue_invite.rs`) : retient les lancements `LaunchBattle` personnalisés et historiques (pas les démos), Oui / Non / Ne plus demander / Échap. Oui envoie le message `StartBattlePrologue` (à brancher : lot bprologue ; il appellera `PrologueInvite::mark_done` en fin de didacticiel). Drapeaux `never_ask` / `done` dans `battle_prologue.json` du dossier `Cent Ans` (le plugin settings n'est pas à ce lot).
Écarts : le lancement de campagne n'est pas retenu par cette invite (la sélection de faction a déjà son invite au guide de campagne) ; filtres en boutons ; image CPU au lieu de dessin vectoriel ; portrait seulement si le fichier fixe existe (pas de variantes vieillies).
Restes : portraits vieillis / archétypes dans les cartes (`court/portrait.rs`), état du didacticiel (bprologue).

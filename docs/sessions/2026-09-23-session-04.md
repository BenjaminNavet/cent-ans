## Leçons
- L'index git est partagé entre sessions : commiter uniquement avec `git commit -- <chemins>`.
- Sur machine chargée, les agents se figent (watchdog 600 s) en générant de gros fichiers : consignes
  « Edit ≤ 40 lignes, premier commit ≤ 5 min, lots étroits » efficaces.
- Après chaque fusion d'une autre session : `./core/build.sh` + `godot --import` avant le smoke (cache de
  classes et dylib partagée).
- Tests de fumée qui dépendent de l'IA sur plusieurs tours : fragiles, à mesurer en Rust plutôt.
